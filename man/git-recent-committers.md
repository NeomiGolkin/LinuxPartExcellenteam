# git-recent-committers(1)

## NAME
git-recent-committers - List people who made commits in the last N days

## SYNOPSIS
`git-recent-committers` [-n days]

## DESCRIPTION
Lists people who made at least one commit in the last N days, along with their commit counts and email addresses.

## ENVIRONMENT
* `GIT_RECENT_COMMITTERS_DAYS`: Controls the default number of days to look back (default is 30 if not set).
